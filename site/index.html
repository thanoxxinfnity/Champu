    01 · The app

    Say what you want. Get the file.

    Chomugiri is a developer workspace in your pocket. You talk to it like a person. It answers questions straight, and when you ask it to make something, it plans the work, writes the files, builds them for real, and gives you the finished result — not a snippet to copy and fix.

    Two lanes, one box

    Everything starts in the same box at the bottom of the screen. Chomugiri reads what you typed and picks a lane by itself.

    • LANE AQuestions. “How does a Kotlin coroutine cancel?” You get a direct answer. No “Great question!”, no padding, no five paragraphs of warm-up. If it needs code, the code comes in a proper block you can copy.
    • LANE BBuilds. “Make me a racing game.” It breaks the job into a checklist of small steps, shows them to you, and ticks them off live as it writes each file and runs each command.

    You never have to choose. If a message is truly in between, it asks a model to decide — otherwise a fast rule-based router does it instantly and for free.

    It plans before it builds

    A big request is turned into an atomic checklist — small steps that each do one thing and can each be checked. You watch the list fill in. Before it starts, it tells you what it guessed (“Camera is third-person. Built in 3D. Named it ‘Racing Forza’ from your prompt.”) so you can say “no, make it 2D” in one line instead of finding out at the end.

    Files land in a built-in file manager, grouped by what they are, and each step reports what it did — “1 file created · 12 lines” — the way a good teammate would write a status update.

    It builds for real

    A phone browser cannot run the Android SDK. So Chomugiri can connect to a small helper on your own computer — the terminal bridge — and run real commands there: gradlew assembleDebug, a Godot export, a zip. The helper only works inside one folder you pick, refuses paths that try to escape it, and you can stop it any time. When a step needs the bridge and you have not connected one, that step is marked blocked instead of pretending it worked.

    If the same command fails the same way twice, the anti-loop guard stops it for good, works out what kind of failure it is — missing tool, bad credentials, broken generated code — and changes approach instead of retrying forever.

    What it can make

    • Android apps — a real Gradle project, a compiled APK, and a zip of the source.
    • Games — Godot 4 projects with levels, sound, and rigged 3D models, exported and packaged. Chomu Horizon, below, came out of this lane.
    • Minecraft add-ons — behaviour and resource packs with real geometry and textures, packed as a .mcaddon you can double-tap to install. It can also convert a Java mod and tell you honestly what did not carry over.
    • Studio — animated slide decks, print-ready documents, spreadsheets, and pictures from several image providers.
    • 3D models — NVIDIA TRELLIS, Tripo, Meshy, or a free model on Kaggle’s GPUs, with a code-built fallback so a build never stops on a missing model.
    • Websites — including real 3D ones — written and deployed to Vercel in one tap, after a check that it will actually build.

    Your models, your keys

    Chomugiri does not lock you to one AI. It talks to the NVIDIA NIM catalogue (dozens of models — Kimi, DeepSeek, Nemotron and more), to a free option with no key at all so it works the moment you install it, and to any OpenAI-compatible address you paste in — including Anthropic- and Gemini-style endpoints. When a model thinks out loud, that reasoning is tucked into a drawer you can open.

    Your keys go in Settings → API Keys, are kept in the phone’s own secret store, and are sent only to the company they belong to. No account. No analytics. The Android app runs its whole backend on the phone, so your message goes from your phone straight to the model provider — no server of ours in the middle.

    Small things you will notice

    • Code blocks have a one-tap copy button that turns into a green tick, and an expand button for reading long code full-screen.
    • Website names wear their logo. Type or read github.com anywhere and it becomes a small pill with that site’s own logo — in the box you type in, in your message, in the answer.
    • Light, dark, or auto — a hand-drawn paper look in both, with fonts built into the app so it looks the same offline.
    • Drafts, a / command palette, your own custom skills, and image or file attachments.
    • Runs in the background — put the app away and a long build keeps going.

    02 · It checks before it builds

    It reads the web, then shows you where.

    Every AI model learned from a snapshot of the internet, and the snapshot goes stale. Ask one about the newest Godot and it may confidently name a version that is two releases old. So before a build, Chomugiri goes and looks.

    type a site name → it gets its logo

    What “researching” means here

    • It works out what it might be wrong about — current version numbers, what changed recently, what the thing you named actually is.
    • It searches the live web and reads the pages, not just the search snippets — release notes, documentation, an encyclopedia entry.
    • It keeps only the facts that matter and builds with them in front of it.
    • Then it tells you what it did: “Researched before building — current Godot version; what changed in Godot 4.x. Read 9 live pages.”

    A real example: asked for a Godot game, it first found that the current Godot is 4.7.2 — something its own memory did not know — and wrote the project for that version.

    Every source has a face

    The pages it read are listed as pills, each with the site’s own logo in front of the name. They look identical everywhere — in the box while you type, in your sent message, in the reply, and in the list of sources — so you can see at a glance whether an answer came from a code host, the docs, or an encyclopedia.

    You can watch it work, too: while it researches, a small status pill at the bottom of the screen says so, with a running timer, and a stop button is always there.

    Logos are fetched once, when the app is built, and shipped inside it — opening this page or the app does not ask any logo company who you are.

    03 · The game

    Chomu Horizon

    An open-world racing game for Android phones, in the spirit of Forza Horizon. Five big maps, nine things to ride, real drifting, nitro, and a garage where you make every one of them yours. It was built with Chomugiri’s own pipeline — which is the only honest way to know that pipeline works.

    5big open-world maps, linked by portals
    9rides — from a supercar to a bicycle and a horse
    3 srewind when you crash
    0accounts, ads or sign-ups

    A world to wander

    There is no race you must enter. You drop onto a map and drive. Roads are carved into real terrain, with forests, rock fields, ramps and coins scattered where a person would put them.

    Horizon HillsRolling green countryside with a lake and long, flowing roads.
    Neo MetroA big, dense Mumbai-styled city. Towers that light up at night, neon shopfronts, traffic.
    Red CanyonA desert mesa run, best at golden hour, all dust and long shadows.
    Frost PeakA snowbound mountain pass with a frozen lake you can drift across.
    Wild TrailAn off-road map made for the trucks and the wilder rides.

    Three glowing portal rings stand on each map’s plaza. Drive through one and you arrive on another map with the same car, the same save, and the same speed.

    Nine ways to ride

    • Supercar (Vortex GT-R), muscle (Brute 69 SS), JDM tuner (Kaze R-Spec — yours free), classic (Relic Custom).
    • Off-road (Ranger Overland) and a monster truck (Titan Crusher) for the Wild Trail.
    • A motorbike (Raptor RR), a bicycle (Pedal One — also free), and a horse (Wild Steed).

    Coins you pick up on the road, in treasure rings and off big jumps buy the pricier ones.

    How it drives

    • Real suspension. Every wheel is a ray cast down at the ground, so cars lean, bounce and land like cars.
    • Drift. Hold the handbrake and the rear wheels let go. Chain drifts for a combo; at ×4 the tyre smoke turns rainbow.
    • Nitro. The ring around the flame button is the tank, and drifting refills it.
    • Big air slows time for a moment; rewind takes you back three seconds.
    • Four camera views you can cycle through, plus free look with an adjustable sensitivity, and a field of view that widens with speed.

    The garage

    A glossy showroom with the car on a turntable. Swipe to spin it, open the doors (swing or scissor), and change the paint — metallic flake, matte, pearlescent, or a chameleon finish that shifts colour as you move. Pick the rims, switch on underglow, and read the stats before you pay.

    Touch controls

    • Left thumb: steer — ◀ ▶ buttons or an analog stick (choose in the garage).
    • Right thumb: GAS and BRAKE (brake, then reverse once stopped), DRIFT, and the nitro ring.
    • Top left: garage, camera, and “put me back on the road”.
    • Every finger is tracked on its own, so you can steer, accelerate and fire nitro at once, and slide a thumb from GAS to BRAKE without lifting.

    How it was made

    Each map’s terrain, road network and object placement is baked offline in Python and shipped as compact data. The trees, rocks, buildings and roadside props were generated by NVIDIA TRELLIS from text descriptions, then trimmed into phone-sized versions with near, far and billboard levels of detail. Custom shaders paint the ground by slope and height, sway the grass, light the city windows at night, ripple the water, crack the ice, and add a final vignette and sharpen pass. The game itself is made with the Godot Engine — hear its licence notice read aloud in three voices ↓.

    03b · New · horror you can think your way out of

    Grinworks

    A first-person horror puzzle game for Android, in the spirit of Poppy Playtime. Grinworks Toy Factory closed eleven years ago. Tonight the lights are out in every room, and its mascot, Mr. Grin, never stopped smiling. You have a torch, a hand crank, a reach glove and four puzzles between you and the factory gate.

    3rules Mr. Grin obeys — every puzzle is about them
    4logic puzzles, each with one provable answer
    7colourful, creepy rooms to light up
    0guns, zombies or jump-scare-only levels

    Who is smiling at you

    • He hears everything. Walking is quiet, running is loud, crouching is nearly silent. Turn a valve, enter a wrong answer or crank the torch and he hears you. A NOISE bar shows what he can hear right now, and a music box tells you he is close.
    • He hates bright light. Hold the torch on him and he recoils and runs. He flinches less each time, and the torch runs down.
    • He cannot enter a lit room. Turn the power back on in a room and it is safe. Light the room he is standing in and he is driven out of it.

    Cubbies hide you — as long as he did not see you climb in. The Reach Glove grabs valves and pick-ups from across the room.

    Four puzzles, four rooms

    Nap roomFour toys, four beds, the name tags have fallen off. Four clues on two notes tell you who sleeps where — and that is the code of cubby 7.
    Boiler roomFive steam valves and five rules from two pages of the manual. Guess wrong and the pipes hammer so loud the whole factory hears.
    Toy labA box of nine breakers where every switch flips itself and its neighbours. Needs the fuse from cubby 7.
    Mascot officeA scrambled word on the lab whiteboard and a cipher key in the cubby. Needs the keycard from the lab.

    Three power cells open the factory gate. It takes 25 seconds, the lights fail while it charges, and Mr. Grin comes for you. Hold him off with the torch.

    Made so that it is finished

    Every puzzle is checked by brute force to have exactly one answer. The map is checked by sweeping a person-sized capsule along every route and aiming at each of its 41 interactive things. Mr. Grin has his own tests (he hears, sees, flinches, will not cross a lit doorway). And before each APK is built, a bot plays the whole game from the loading dock to the gate with the real controls, twice — once with Mr. Grin really hunting. If any of that fails, there is no APK.

    The toys, the props and Mr. Grin were generated from text by Microsoft TRELLIS on NVIDIA NIM, then trimmed to phone size. The game is made with the Godot Engine.

    04 · Built with Godot

    Made with Godot Engine

    Chomu Horizon, and every game Chomugiri builds, runs on the Godot Engine — a free, open-source game engine. Godot asks everyone who ships a game with it to show its licence notice. So here it is, three times, read aloud.
