Four things it finishes

Minecraft add-ons

Manifests, real v4 UUIDs, a lang file, painted 16×16 textures and Blockbench geometry — zipped into a .mcaddon that actually imports.

Android apps

A full Gradle project, compiled to an APK when your terminal bridge is connected. Offline, it writes every source file and tells you which step is parked.

Websites

This page is the proof. One module, no bundler, three.js pinned — previewed inside the app at phone, tablet and full width before it ever ships.

MCP servers

Model Context Protocol scaffolds for Claude Code and Cursor: tools, resources and schemas that pass validation on the first run.

How a run goes

  1. It reads the intent. A question gets answered. A build gets built. It does not confuse the two.
  2. It plans out loud. Atomic steps land in a live checklist you can watch tick over.
  3. It narrates each file. “Creating bp/manifest.json — the pack's identity.” Never a wall of code with no commentary.
  4. It keeps going when you leave. A backgrounded run holds the process open and tells you when it is done.

Built on a phone, for a phone.
