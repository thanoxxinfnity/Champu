# Chomu Dead

A third-person zombie-survival horror game for phones, in the spirit of Walking Zombie 2.
**Every 3D model in it — Rohan, the ghouls, the guns, the cars, the houses, the church —
was generated by Microsoft TRELLIS** (through NVIDIA's hosted API) from a one-line prompt.

*Saint Aster, 02:14 AM.* You wake up in the clinic. The town went dark an hour ago.
Find a gun, find the others, get out alive.

## The story (7 chapters)

1. **The Ward** – wake up in the clinic, find the pistol in the nurse's cabinet, fight out.
2. **Dead Streets** – walk Main Street to the police car; a radio crackles: Doctor Iyer, in the church.
3. **The Gas Station** – bolt cutters and a shotgun, guarded by a bloater.
4. **The Church** – cut the chain on the churchyard gate.
5. **The Long Night** – hold the yard against five waves while the radio signal goes out.
6. **The Warden** – a rifle from the vestry, then the hospital yard and a chained, towering boss
   (charges, ground-slams, calls a pack when he is half dead).
7. **Escape** – run for the helicopter.

Six notes lying around the town fill in what happened. Dying restarts the current chapter.

## What is in it

- **4 guns** — M9 pistol, pump shotgun, MP7 SMG, AK rifle — with magazines, reloads, recoil, headshots
  (x2.4), tracers, muzzle light, and aim assist so a thumb on glass is as accurate as a mouse.
- **6 enemy kinds** — walker, runner (screams), cop (armoured), nurse, bloater (explodes), the Warden.
- **Night, rain and lightning**, fog, a flickering-light clinic, a flashlight, pickups with light beams.
- **Procedural audio** — every sound (guns, groans, thunder, wind, heartbeat) is synthesised at start-up.
- **Touch controls** — floating stick, free-look, FIRE / RELOAD / SWAP / LIGHT; WASD + mouse on desktop.

## How the models are animated

TRELLIS gives one rigid mesh per model — no skeleton. `shaders/puppet.gdshader` finds the legs and
arms from where each vertex sits in the model's bounding box and swings them about the hip and
shoulder in the vertex stage (stride, arm-swing, reach, hunch, limp, hit flash). It is cheap enough
for a dozen ghouls on a phone.

## Rebuilding the models

```bash
export NVIDIA_NIM_API_KEY=nvapi-...
node --experimental-strip-types tools/gen_trellis.mjs <raw_dir>      # TRELLIS -> raw .glb (re-runnable)
python3 tools/prep_dead.py <raw_dir> assets/dead                      # simplify + shrink textures
godot --headless --path . --import
```

What was learned about the API while building this (all in `tools/gen_trellis.mjs`):
short prompts answer in ~11 s while long "photorealistic, PBR, game-ready…" ones stall; the word
"zombie" (and some gun words) is refused instantly by the content filter, so the undead are ghouls
and a gun is asked for in several wordings.

## Tests

```bash
godot --headless --path . --fixed-fps 60 -s tests/smoke.gd        # ward fight, pistol, leave the clinic
godot --headless --path . --fixed-fps 60 -s tests/playthrough.gd  # the whole story, death + retry, ending
xvfb-run godot --path . --rendering-driver opengl3 -s tests/shots.gd -- <dir> [action|screens]
xvfb-run godot --path . --rendering-driver opengl3 -s tests/viewer.gd -- <dir> [names|guns] [reach] [walk]
```

## Build an APK

```bash
godot --headless --path . --export-release "Android" build/ChomuDead.apk
```

CI does this on every push (`.github/workflows/chomu-dead-apk.yml`) and publishes the APK to the
`chomu-dead-apk` release.
